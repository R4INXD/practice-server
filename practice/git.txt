# 스테이징 staging
스테이라고 하는 대기실이 있다.
다른 사람들에게 공유 하고싶은 코드를 스테이지에다가 등록하는 행위를 '스테이징'이라고 합니다.
스테이징 하는 방법: git add <파일명 또는 폴더명>
변경사항이 있는 모든 파일을 스테이징 하는 방법: git add .

# 커밋 commit
스테이징 한 파일들의 변경사항을 하나의 히스토리로 저장하는 행위
커밋에는 메세지가 필요하다. 현재 변경사항을 가장 잘 나타내는 말을 쓰면 돼요.
git commit -m "<커밋 메세지>"

# 푸시 push
커밋한 내용은 기본적으로 내 컴퓨터에만 저장이 돼있어요.
내 컴퓨터에 내가 커밋한 내용을 다른 사람들에게 공유하기 위해서 업로드 하는 행위를 '푸시'라고 해요.
git push

# 풀 pull
다른 사람들이 공유한 내용을 내 컴퓨터로 불러오는 행위를 '풀'이라고 해요.
git pull

깃을 사용하는 방법은 크게 2가지가 있어요.
1. CLI (Command Line Interface): 터미널에서 명령줄을 입력하여 실행
2. GUI (Graphical User Interface): 버튼을 클릭해서 실행

================================================================================

'깃'과 '깃허브'는 다르다.
개발 입문자들의 경우, 흔히 '깃'과 '깃허브'를 같은 개념으로 착각하곤 합니다.

'깃'은 버전을 관리하기 위한 프로그램입니다. // MP4 파일
'깃허브'는 깃을 사용해서 만든 히스토리를 다른 사람들과 원격으로 공유할 수 있게 해주는 웹 서비스입니다. // 유튜브 사이트
